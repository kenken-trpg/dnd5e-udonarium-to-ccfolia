D&D5e ココフォリア変換

D&D5e ユドナリウムPCコマ生成ツールで保存したコマ（ZIP）を、 ココフォリアに貼り付けられるキャラクターデータへ変換します。 変換はこのブラウザの中だけで行い、ファイルはどこにも送信しません。

1. ユドナリウムのコマを用意する

  1. D&D5E キャラクターデータベースで、キャラクターシートのURL（https://dndjp.sakura.ne.jp/OUTPUT.php?ID=…）をコピーする。
  2. D&D5e ユドナリウムPCコマ生成ツールにURLを貼り付けて生成し、ZIPを保存する。

2. 読み込む 生成ツールで保存したZIPか、その中のXMLを読み込めます。複数まとめて選べます。1ファイル 20MB まで。

保存した ZIP（または中の XML）をここにドロップ、またはクリックして選択

3. 出力オプション

背景・人格的特徴・尊ぶもの・関わり深いもの・弱味などを、【見出し】付きでメモの末尾に追加します。 {筋力修正} などを、変換した時点の数値に置き換えます。置き換えると、あとでココフォリアのパラメータを書き換えてもパレットは変わらなくなります。 ココフォリアのキャラクター設定の「色」に入ります。

ココフォリアはパレット中の {筋力修正} などをパラメータの値に置き換えるので、通常は置き換え不要です。

ココフォリアへの貼り付け方

  1. 「ココフォリア用にコピー」を押す。
  2. ココフォリアのルームを開き、盤面をクリックしてから Ctrl+V（Mac は ⌘+V）。
  3. ダイスボットを「ダンジョンズ＆ドラゴンズ第5版」にすると、AR / AT コマンドが使えます。

立ち絵は引き継がれません。貼り付け後にココフォリアで設定してください。

同じ変換ができる Streamlit版 もあります。 ソースコード: GitHub
