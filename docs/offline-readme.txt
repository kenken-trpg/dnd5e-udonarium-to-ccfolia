D&D5e ココフォリア変換（手元で使う版）

使い方
  1. このフォルダの index.html をダブルクリックしてブラウザで開きます。
  2. D&D5e ユドナリウムPCコマ生成ツールで保存したZIPを、画面の枠にドロップします。
  3. 「ココフォリア用にコピー」を押し、ココフォリアの盤面で Ctrl+V（Mac は ⌘+V）を押します。

  index.html / app.js / converter.js / style.css の4つは、同じフォルダに置いたままにしてください。
  変換はブラウザの中だけで行い、ファイルはどこにも送信しません。

公開ページ（インストール不要）
  https://kenken-trpg.github.io/dnd5e-udonarium-to-ccfolia/

マニュアル・よくある質問
  https://github.com/kenken-trpg/dnd5e-udonarium-to-ccfolia/blob/main/docs/manual.md

読み込み上限: 一度に50ファイル・50体、入力の合計20MBまで。
XMLは1つ5MB、ZIPの展開後・一度の変換対象XMLの合計は20MBまでです。
「?」はマウス・タップ・キーボードのTabで説明を表示し、Escで閉じられます。
