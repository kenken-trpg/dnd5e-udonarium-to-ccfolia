D&D5e ココフォリア変換（手元で使う版）

使い方
  1. このフォルダの index.html をダブルクリックしてブラウザで開きます。
  2. D&D5e ユドナリウムPCコマ生成ツールで保存したZIPを、画面の枠にドロップします。
  3. 「ココフォリア用にコピー」を押し、ココフォリアの盤面で Ctrl+V（Mac は ⌘+V）を押します。

  index.html / app.js / converter.js / style.css の4つは、同じフォルダに置いたままにしてください。
  変換はブラウザの中だけで行い、ファイルはどこにも送信しません。
