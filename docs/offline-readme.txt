D&D5e ココフォリア変換（手元で使う版）

使い方
  1. このフォルダの index.html をダブルクリックしてブラウザで開きます。
  2. D&D5e ユドナリウムPCコマ生成ツールで保存したZIPを、画面の枠にドロップします。
     複数のファイルをまとめて選べます。読み込み中は進捗が表示され、「読み込みをキャンセル」で中断できます
     （変換済みの結果は残ります）。
  3. 「ココフォリア用にコピー」を押し、ココフォリアの盤面をクリックしてから Ctrl+V（Mac は ⌘+V）を押します。

  変換はブラウザの中だけで行い、ファイルはどこにも送信しません。インターネットにつながっていなくても使えます。

  画面の「?」を押すと説明が開き、もう一度押すと閉じます（スマホはタップ）。ボタンはマウスを少し乗せたままにするか、
  キーボードの Tab で移動すると説明が出ます。どちらも Esc で閉じます。

結果の整理と保存
  「この結果を削除」で1体ずつ外せます。「すべてクリア」で結果をすべて消します（出力オプションの記憶は残ります）。
  「全員分をZIPで保存」はバックアップ用です。ココフォリアへは、展開した各JSONの中身をコピーして1体ずつ貼り付けてください。

フォルダの中身
  index.html / app.js / converter.js / archive.js / style.css / manual.html と images フォルダは、同じフォルダに置いたままにしてください。
  どれかが欠けると動きません。

マニュアル・よくある質問
  このフォルダの manual.html（画面下の「マニュアル」からも開けます）。
  動画マニュアル（YouTube・約1分30秒。インターネット接続が必要です）: https://www.youtube.com/watch?v=qQDg6C3P3Zo

読み込みの上限
  一度に50ファイル・50体、入力の合計20MBまで。
  XMLは1つ5MBまで、ZIPの展開後・一度に変換するXMLの合計は20MBまでです。
