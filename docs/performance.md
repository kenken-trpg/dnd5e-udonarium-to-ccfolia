# 性能計測

`npm run benchmark` はアプリをChromiumで直接開き、通常のXMLとパレットを256KiB増やしたXMLを、それぞれ1・10・50体読み込ませます。
各条件で1回ウォームアップしてから5回測定し、各回の値と中央値をJSONに保存します。

```sh
npm ci
npx playwright install --only-shell chromium
npm run benchmark
# 保存先を指定する場合
npm run benchmark -- /tmp/dnd5e-benchmark.json
```

標準の保存先は `.local-artifacts/benchmark/latest.json` です。PlaywrightのE2Eと同時に実行しないでください。

## 測定するもの

- **解析**: XMLから中間データへの変換。
- **変換**: 中間データからココフォリアJSONのオブジェクトへの変換。
- **DOM更新**: 警告の診断、概要・パレット・メモのDOM更新、JSONの整形を含む。ブラウザのレイアウト・描画完了時間ではありません。
- **総時間**: 自動操作によるファイル選択開始から、全キャラクターの結果を確認して2描画フレーム待つまで。ファイルの読み取り、デコード、入力の転送、検査、イベント待機、自動操作などを含みます。

出力オプションは既定、詳細欄は閉じた通常の初期表示で測定します。
解析・変換・DOM更新の値は、対象キャラクター全体の同期処理時間の合計です。
各列の中央値は独立に求めるため、各列の合計が総時間と一致するとは限りません。
小さい値はブラウザの時刻精度で0.00msと表示される場合があります。
これらはメモリ使用量や最も遅い1回の待ち時間を測るものではありません。

## 初回の測定結果

測定日: 2026-11-18。単位は時間がms、入力がバイトです。
環境: Apple A18 Pro, darwin arm64, Node v24.14.1, Chromium 159.0.8154.6、1280×800。

| 入力 | 体数 | 入力合計 | 解析 | 変換 | DOM更新 | 総時間 |
|---|---:|---:|---:|---:|---:|---:|
| 通常XML | 1 | 8,755 | 0.20 | 0.00 | 0.10 | 32.86 |
| 通常XML | 10 | 87,550 | 1.70 | 0.10 | 0.50 | 49.58 |
| 通常XML | 50 | 437,750 | 6.30 | 0.60 | 2.20 | 67.12 |
| 大きなパレット | 1 | 270,904 | 1.30 | 0.00 | 0.60 | 49.63 |
| 大きなパレット | 10 | 2,709,040 | 11.10 | 0.10 | 4.50 | 166.21 |
| 大きなパレット | 50 | 13,545,200 | 51.70 | 0.90 | 21.30 | 782.41 |

生データ・入力のSHA-256・各回の測定値は [2026-11-18.json](benchmarks/2026-11-18.json) にあります。
元の入力は匿名サンプル `tests/fixtures/attacks.xml` です。大きなパレットは、その末尾にロールしないコメントとしてASCII文字を256KiB追加した合成データです。

この環境では、大きな入力50体でも総時間の中央値は1秒以内でした。同期処理のうち解析が最も大きく、JSONオブジェクトへの変換自体の割合は小さくなっています。
総時間には別の処理や待機も含まれるため、解析を非同期化するだけで総時間が同じ割合短くなるとは判断できません。
現段階ではWeb Workerを追加せず、より低速な端末や詳細欄を開く操作で長い停止が確認された場合に検討します。

環境や負荷で結果が変わるため、CIでは固定の時間閾値を設けません。同じ環境・入力・ブラウザ版で比較してください。
